# **App Name**: Knowledge Nexus

## Core Features:

- User Authentication: Secure login and registration interface capturing user's full name, username, phone, email, password, gender, birthday, nationality, address, and language.
- User Profile Management: Allows users to view and update their personal information registered during sign-up, ensuring their profile is up-to-date for recommendations.
- Personalized Recommendation Dashboard: Displays categorized recommendations for 'projects', 'experts', 'enterprises', and 'funders' based on user preferences and knowledge graph insights.
- Entity Detail Pages: Dedicated pages to showcase comprehensive details for each recommended entity (project, expert, enterprise, or funder).
- Search & Advanced Filtering Interface: Provides an intuitive interface for users to search and apply filters across all knowledge graph entities (projects, experts, enterprises, funders).
- AI-Assisted Knowledge Graph Exploration Tool: An AI-powered tool that allows users to ask natural language questions about the knowledge graph, generating more precise search queries or offering synthesized insights.

## Style Guidelines:

- Primary color: A strong black (#000000) for headers, critical interactive elements, and text, conveying sophistication and professionalism.
- Background color: Pure white (#FFFFFF) serving as the main canvas, ensuring maximum readability and a clean, spacious feel.
- Accent and neutral colors: Various shades of grey (e.g., #333333 for secondary text, #BBBBBB for borders and separators) are used to create subtle visual hierarchy, contrast, and highlight details without overwhelming the user interface.
- Headlines will use 'Space Grotesk' (sans-serif) for a modern, tech-forward, and bold appearance, aligning with the concept of a knowledge graph. Body text will use 'Inter' (sans-serif), ensuring excellent readability for longer content blocks and general information.
- Use a consistent set of clean, professional, and easily recognizable line icons. Distinct icons should represent each entity type: 'project', 'expert', 'enterprise', and 'funder' to aid navigation and understanding.
- Adopt a clean, structured, and spacious layout that prioritizes content legibility. Utilize clear card-based designs for recommendations and maintain logical grouping of information, ensuring responsiveness across devices.
- Implement subtle, purposeful animations for user feedback, such as hover effects on interactive elements, smooth transitions during data loading, and concise form submission confirmations, to enhance perceived performance without distraction.
